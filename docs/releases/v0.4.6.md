# Version 0.4.6

Cette version renforce et rend visibles les contrôles de sécurité de la chaîne
de publication.

- Le certificat de signature historique est vérifié avant toute publication,
  afin que l’APK reste installable comme mise à jour par les utilisateurs
  existants.
- Les dépendances d’exécution sont exportées dans un SBOM CycloneDX et
  vérifiées par OSV-Scanner avant la release.
- Une vulnérabilité connue ou une analyse OSV incomplète bloque la publication.
- Les rapports lisibles, JSON et SARIF sont publics dans la release et sur la
  page GitHub Pages.
- Les builds vérifient les empreintes Gradle, produisent des attestations de
  provenance et de SBOM, et utilisent des actions GitHub épinglées par SHA.
- CodeQL, Dependabot, la revue des dépendances, le secret scanning et le
  signalement privé de vulnérabilités complètent ces contrôles.
